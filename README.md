<summary><b>🧵 ThreadShare — Peer-to-Peer Fashion Exchange App</b> <em>(Main Project)</em></summary>

> A full-stack wardrobe management and peer fashion exchange platform with a closet dashboard, outfit builder, and wear logging. Also served as a DBMS course project with professional-grade relational design.

**Stack:** `Next.js` `PostgreSQL` `Auth.js v5` `Tailwind CSS` `Vercel`

**Highlights:**
- PostgreSQL triggers auto-update wear stats and item status on each log entry
- Stored procedures and views for cost-per-wear calculations
- 7 normalized tables covering users, items, outfits, and transactions with ACID guarantees
- Session-based authentication via Auth.js v5

🔗 [fashion-closet-management.vercel.app](https://fashion-closet-management.vercel.app)
