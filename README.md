## `> projects --featured`

<details open>
<summary><b>🔐 Nexus — Self-Hosted E2EE Messaging Platform</b></summary>

> A production-grade Signal Protocol encrypted messaging system with web, Android, and iOS clients. Designed with system design interview architecture in mind.

**Stack:** `Fastify` `uWebSockets.js` `Drizzle` `Redis Pub/Sub` `BullMQ` `PostgreSQL` `Kotlin/Jetpack Compose` `Swift/SwiftUI`

**Highlights:**
- Signal Protocol end-to-end encryption
- Real-time messaging via WebSockets with Redis pub/sub fanout
- Native Android (Kotlin + Jetpack Compose) and iOS (Swift + SwiftUI) clients
- Queue-based background job system using BullMQ

</details>

<details>
<summary><b>🛡️ ShelfIQ — Retail Shelf Intelligence System</b></summary>

> A CV-powered retail intelligence platform built for the Prama Innovations Hackathon. Led team XO Hunters to build a full pipeline from shelf image to business insight.

**Stack:** `YOLOv8` `FastAPI` `PostgreSQL + TimescaleDB` `Prophet/LSTM` `Next.js 14`

**Highlights:**
- Real-time shelf product detection using YOLOv8
- Demand forecasting with Prophet and LSTM models
- All ordering decisions kept manual — no auto-ordering by design

</details>

<details>
<summary><b>🤖 MopBot-RL — Reinforcement Learning Mopping Robot</b></summary>

> Built for the Scaler x Meta PyTorch Hackathon and an OpenEnv Hackathon. A full OpenEnv-compliant RL environment with three difficulty-tiered tasks.

**Stack:** `PyTorch` `FastAPI` `Pydantic v2` `Docker` `HuggingFace Spaces`

**Highlights:**
- Custom RL environment with grader-based evaluation
- Deployed to HuggingFace Spaces
- Served as team lead for hackathon

</details>

<details>
<summary><b>🧵 ThreadShare — Peer-to-Peer Fashion Exchange App</b></summary>

> A wardrobe management and fashion exchange platform. Also served as a DBMS course project with full relational design.

**Stack:** `Next.js` `PostgreSQL` `Auth.js` `Tailwind CSS` `Vercel`

**Highlights:**
- 7-table schema with triggers, stored procedures, views, and ACID transactions
- Deployed on Vercel

</details>

<details>
<summary><b>🍱 Indian Food Calorie Detection (YOLO)</b></summary>

**Stack:** `YOLOv8` `LabelImg` `Food-101` `USDA JSON lookup`

**Highlights:**
- Self-labeled dataset (no pre-annotated data used)
- Focused on Indian food classes

</details>
